# Тайцзи-Цигун · Новосибирск — демо главной «Час до города»

Одна страница — один утренний час практики, 08:00—09:00. Справа идёт шкала часа: вверху 08:00, в футере 09:00.
Визуальный код — береста и тушь плюс одна красная печать 太极.

Статика без сборки: `index.html` + `css/style.css` + `js/*.js`. GSAP 3.13 (ScrollTrigger, Flip) с cdnjs, Lenis 1.3.11 с jsDelivr.
Сайт открывается двойным кликом по `index.html` и выкладывается как статика (для РФ — GitHub Pages, не Vercel).

```
node tools/serve.mjs 8090        # локальный сервер (конфиг «taichi» в общем .claude/launch.json)
```

## Что на странице

00 Прелоадер «Вдох»: круг вдох/выдох → печать → Flip в логотип шапки. Показывается один раз за сессию, клик пропускает.
01 Шапка прячется при скролле вниз. 02 Hero: 太极拳 проявляются кистью, в canvas — дымка и след туши за курсором, погода с Open-Meteo.
03 Манифест по словам с мазками под «дышать» и «медленнее». 04 Sticky-сцена 320vh: круг тайцзи пишется кистью в три фазы и сжимается в печать.
05 Шар дыхания: мышь, тач, пробел, три цикла. 06 Оглавление практик 一—五.
07 Неделя по времени Новосибирска. 08 Учитель. 09 Чайная карта цен. 10 Путь в 4 шага + карта. 11 «Ближайшее утро» с отсчётом. 12 Футер «09:00».
Раздел «Площадка» с лентой фото убран по просьбе Артёма (16.10.2026).

Проверить расписание с подменой времени (новосибирского): `index.html?now=2026-10-20T08:37`.
